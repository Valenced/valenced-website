## Discord server

[**Join the Valenced Discord**](https://discord.com/invite/dtBTQHYSx4)! Ask in the support channels and include:

- Your **Discord app version** and **Valenced version** (shown in Settings > Valenced).
- Your **install method** (Valenced Manager or the Xposed module) and Android version.
- A **crash log** if you have one (visible on the error screen, or via `adb logcat`).

## GitHub issues

Found a reproducible bug or have a feature request? Open an issue on the relevant repository:

| Problem area | Repository |
| --- | --- |
| The client mod itself (plugins, UI, settings, loaders) | [valenced](https://github.com/Valenced/valenced/issues) |
| Community plugins | [valenced-community-plugins](https://github.com/Valenced/valenced-community-plugins/issues) |
| Android installer | [valenced-manager](https://github.com/Valenced/valenced-manager/issues) |
| Developer tools | [revenge-devtools](https://github.com/revenge-mod/revenge-devtools/issues) |

Please search existing issues before opening a new one, and include reproduction steps.

<Callout title="Plugin problems">
    If a third-party plugin is misbehaving, report it to the **plugin's author** first. Valenced issues should be about Valenced itself.
</Callout>
