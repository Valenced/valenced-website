## Plugins

Extend Discord with custom features. Plugins can tweak almost anything in the app: add custom UI, change behavior, remove annoyances, or introduce entire new features.

- **Built-in plugins**: Valenced ships with essential utilities out of the box, including tracking blockers, staff settings (experiments), crash recovery, and the settings UI.
- **External plugins**: Install community plugins directly from the in-app plugin browser or by sideloading ZIP files.
- **Updates your way**: Plugins update in the background. Follow a release channel, stay on a version, or pause updates for any plugin.

## Themes

Make Discord look how you want with custom color themes, background images, font packs, icon packs, and emoji packs. Themes are plugins, so they install and update like any other plugin.
Pick colors, fonts, icons, and emoji separately, and mix packs from different plugins. Themes and font packs made for Vendetta and Bunny can be imported too.

## Recovery

If a plugin breaks your client, Recovery Mode starts Discord with only the built-in default plugins so you can fix things. Valenced enters it on its own after repeated crashes at startup. See [Common Issues](/docs/troubleshooting/common-issues) for more.

## Experiments

Try upcoming Discord features before they roll out. The **Staff Settings** plugin lets you toggle internal Discord experiments and staff flags to explore new features early.

## Developer tooling

Valenced is built for developers:

- Composable and well-structured [plugin runtime API](/docs/plugin-development).
- Native plugins support with [IPC bridge](/docs/plugin-development/api-reference/native).
- [Plugin template](/docs/plugin-development/getting-started/the-plugin-template) and tooling included.
- Live inspection and code execution via [Valenced DevTools](/docs/devtools), complete with MCP support for AI agents.
