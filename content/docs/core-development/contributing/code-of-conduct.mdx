The Valenced community (GitHub repositories, Discord server, and associated project spaces) is dedicated to providing a constructive environment for collaboration.

## Standards

**Do:**

- Be respectful and constructive. Critique code and technical ideas directly rather than individuals.
- Help newcomers navigate client modding concepts.
- Assume good faith during discussions.
- Use public channels for support and technical questions so solutions remain searchable.

**Don't:**

- Harass, insult, or discriminate against community members.
- Spam, self-promote, or derail technical discussions.
- Distribute or request tools intended for malicious behavior or API abuse (including token stealers, self-bots, and scrapers).
- Post private personal information without consent.

## Scope

These standards apply across all official Valenced spaces, including the [Valenced GitHub organization](https://github.com/Valenced) and the [Discord server](https://discord.com/invite/dtBTQHYSx4).

## Enforcement

Maintainers and moderators may edit or delete messages, lock issues, and restrict access for policy violations. Report incidents to project maintainers or moderators in the Discord server.
