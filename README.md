## 👷 Developing

1. Install [Bun](https://bun.sh/) or [Node.js](https://nodejs.org/en/download/).
2. Clone the repository.
3. Install dependencies

    ```bash
    npm install
    # or
    bun install
    ```

4. Run development server

    ```bash
    npm run dev
    # or
    bun dev
    ```
